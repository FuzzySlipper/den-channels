Den Channels — Backend API Service

This server hosts the Den Channels backend API. The primary Den Web frontend lives elsewhere.

→ Go to Den Web

The embedded Channel Chat SPA was retired in task #1708. All frontend product work now routes to the den-web repo.

API endpoints

  • /health/live — process liveness
  • /health/ready — readiness check
  • /api/service-info — service metadata
  • /api/channels — channel CRUD
  • /api/channels/{id}/messages — channel messages
